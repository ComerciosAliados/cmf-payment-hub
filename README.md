# CMF Payment Hub

Hub de pagos centralizado para CMF Panamá.

> ⚠️ **Repositorio público de demostración.** Todos los datos son ficticios. No contiene credenciales, datos de clientes ni configuración de sistemas internos.

## Estado

Fase inicial: definición de alcance y demo estática en GitHub Pages.

Ver [`CLAUDE.md`](CLAUDE.md) para el contexto del proyecto, la arquitectura propuesta y las reglas del repositorio.

## Demo

👉 **https://comerciosaliados.github.io/cmf-payment-hub/**

1. Entra con un perfil (Administrador, Supervisor, Gestor o Auditor). Cada perfil ve opciones distintas.
2. Crea un **Nuevo cobro**: solo cliente, monto y concepto.
3. Abre el link como cliente (o envíalo por WhatsApp), elige método de pago y paga (simulado).
4. Vuelve a **Cobros**: el estado cambia a **Pagado**.

Botón **Reiniciar demo** en la barra lateral para restaurar los datos de ejemplo.
